# EMJ Digital Studio: brand sheet

Always write the full name: **EMJ Digital Studio**. "EMJ" alone is also used by other organisations.

## Logo files (`brand/`)
| File | Use |
|---|---|
| `emj-logo-light.svg` | on Off-White and white: charcoal letters, indigo square |
| `emj-logo-dark.svg` | on Charcoal and the dark theme: off-white letters, soft indigo square |
| `emj-logo-on-indigo.svg` | on the indigo brand colour: the square turns off-white (an indigo square would vanish) |
| `emj-logo-one-colour.svg` | stamps, print, watermarks |
| `emj-symbol-indigo.svg` / `emj-symbol-charcoal.svg` | square symbol: favicon, avatars, app icons |

Rules: smallest logo height 20px (strokes 4px). Clear space on every side: 16 units, which is 40% of the logo height (8px when the logo is 20px tall).
Never recolour, stretch, outline or add effects.
In the header the lockup is the monogram (20px tall), a 12px gap, then "Digital Studio" in Familjen Grotesk Medium, 16px.

## Type
Familjen Grotesk (400, 500, 600) for text. IBM Plex Mono (400 only, never bold) for metadata: numbers, labels, sizes, status.
Roles: display (hero, 4xl to 6xl), section title (5xl), project title (3xl), item title (xl to 2xl), body (base to lg),
interface text (sm), metadata (mono xs).

## System
Sharp corners, 1px borders, no shadows. 8pt grid for layout and sizes; 4px half-steps allowed inside components.
Controls are 40px tall. Anchors: drawer 320px, meta column 256px. Square motif (8px squares) for markers and handles.
Motion: one entrance on the hero, colour transitions on hover; everything respects reduced motion.

## Voice
Plain and factual. "We" on studio sections, "I" on a person's profile page. No claims without a case study behind them.
